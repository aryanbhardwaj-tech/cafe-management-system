# Cafe Management System

A simple Python console application for Elevate Cafe that lets customers view the menu, place orders, and get the total bill.

## Features
- Displays the cafe menu with prices
- Lets the customer order items by name
- Supports ordering a second item
- Calculates and shows the total amount to pay

## How to run
1. Install Python 3
2. Download or clone this repository
3. Run:

   python hotelmenu.py
